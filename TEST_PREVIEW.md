# Modern Client Test Preview

This branch and its compiled package are an experimental test preview. They are
not a production-ready Noggit release.

## Verified

- Wrath of the Lich King editing remains available, including 16 texture layers.
- Shadowlands 9.2.7 CASC reading, map selection, and map entry work.
- Retail 12.1 CASC reading, map selection, and map entry work.
- Modern M2 and WMO rendering is approximately 85-90% complete.

## Known limitations

- Modern M2/WMO materials, effects, lighting, and some textures still have
  rendering defects.
- Saving for Shadowlands and Retail is not connected yet. Do not use this
  preview for modern map editing or production data.
