# ShadowWorld Noggit v1.4.6 — Retail rendering and deferred map generation

## Changes

- Integrates Allen's PR #9: Retail terrain blending, model lighting, precise holes, and texture upload improvements.
- Ordinary saves defer derived terrain generation by default. Source ADT edits can be saved while derived results remain pending; use the project LOD/map-texture/heightmap update command before export.
- Legacy path-addressed split maps without a terrain LOD asset no longer remain permanently blocked waiting for one. Modern WDT references still require their LOD assets.
- Primary-only M2 additions preserve existing Retail OBJ1 LOD metadata.
- Retail terrain blending is consistent across up to 16 layers, including material UV scale and phase. Terrain holes, M2 alpha-key rendering, WMO lighting and texture-array uploads have additional regression coverage.
- Texture readiness, asynchronous loading completion and tile-removal handling have been improved. Map-texture export avoids an intermediate PNG conversion.

## Validation and limits

Validation: all 36 regression tests passed, including OpenGL sampling of every compressed texture-array layer. Windows Release build completed.

These checks do not establish complete visual parity with every game-client build. Unsupported layouts remain guarded. Deferred LOD/map textures/heightmaps must be updated before testing or publishing an edited map; see [derived map results](../derived-map-results.md).

## Packages

Download and extract the complete Windows x64 ZIP, then run `Start-ShadowWorld-Noggit.cmd` or `noggit.exe`. Preserve your projects and existing configuration when upgrading. Personal projects, logs, machine-specific configuration and debug runtimes are excluded.

The complete-source ZIP includes initialized submodules and dependency source snapshots. Git checkout users should initialize submodules and run `tools/apply-local-dependencies.ps1` for the tracked compatibility patches. The canonical Git source remains the maintained project; packaged sources are release snapshots. SHA-256 checksums are supplied for both ZIPs.
