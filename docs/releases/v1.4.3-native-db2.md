# ShadowWorld Noggit v1.4.3 - Native DB2 Release

One Windows x64 executable for WotLK, Shadowlands 9.2.7, Retail and Forever projects.

## Native Modern Database Saves

- New maps and edited map metadata save to native `Map.db2`.
- Area, trigger, lighting, ground effect, music and ambience changes save
  to their corresponding modern DB2 tables rather than legacy DBC overrides.
- Source container version/layout and untouched fields are preserved.
  Unsupported layouts and unresolved encrypted sections report an error.
- Includes native database definitions and public TACT key support for the
  tested Shadowlands Map table. WotLK continues to save DBC and WotLK ADTs.

## Verified

- Round-trip tests passed for 11 Shadowlands editor tables: AreaTable,
  AreaTrigger, Light, LightParams, LightData, LightSkybox,
  GroundEffectTexture, GroundEffectDoodad, SoundAmbience, ZoneMusic and
  ZoneIntroMusicTable.
- Native Map writer tests passed for Shadowlands WDC3 and Retail WDC5.
- The project author confirmed new-map save/reopen on Shadowlands
  `Teszt-1`, including six terrain texture layers, M2 placements and water.

## Included

The previous split-ADT SaveFix, PNG alphamap import/export for layers 1-15,
16-layer terrain editing across all project types, and the animated
ShadowWorld selector. Modern terrain and M2/WMO placement saves retain the
project's native format. The base texture has no alphamap.

## Download

Extract the entire Windows ZIP and run `Start-ShadowWorld-Noggit.cmd`.
Runtime libraries, native DB2 definitions, themes and a listfile are included.
No personal projects, logs, backups, debug binaries or assistant reports are
included. The complete source ZIP also contains the pinned dependencies.

Full SoundKit/SoundKitEntry editing and cross-version conversion are not
included. Not all BFA/Retail/Forever builds have been tested; this release does
not claim to resolve every reported modern rendering issue. Back up maps
before editing; multi-file rollback is not power-loss recovery.
