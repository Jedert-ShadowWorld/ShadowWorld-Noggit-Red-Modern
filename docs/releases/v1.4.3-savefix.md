# ShadowWorld Noggit v1.4.3 - SaveFix Release

One Windows x64 executable for WotLK, Shadowlands 9.2.7, Retail and Forever
projects. This release includes the modern-client updates prepared since
v1.4.2 and the verified Shadowlands save-chain fix.

## Save Fixes

- Accept shipped OBJ1 layouts with or without optional MLDL and MLFD chunks.
- Handle empty M2/WMO placement lists without rejecting the tile.
- Preserve the source layout's optional chunks when rewriting placements.
- Stage the complete split ADT tile before replacing its project files.
- On a later commit failure, restore already committed overrides where possible
  and report any rollback failure explicitly.
- Forward failed tile saves to the editor instead of displaying "Map saved".
- Keep failed tiles marked as changed and retain undo history on failure.
- Update horizon data only after the corresponding tile saves successfully.
- Avoid truncating the previous ADT before the serializer starts.

## Validation

- 147 checks using all 36 original Hillsbrad OBJ1 files: unchanged save,
  placement movement, addition, removal, repeated saving and malformed LOD data.
- Four Windows file-write checks: staging failure, rollback of an existing
  file, rollback of a newly created file, and successful complete saving.
- In-editor Shadowlands 9.2.7 save/reopen confirmed by the project author on
  Hillsbrad and Lost Isles, including terrain painting and M2/WMO placements.
- The Lost Isles save log reported 40 successful tile saves and no save failures.
- Packaged executable launched and remained responsive in the project selector.

## Other Included Updates

- Retail DB2 definition selection can match an existing layout hash when
  the exact newer client build is not yet listed.
- Alphamap PNG import/export exposes alpha layers 1-15.
- Multi-layer texture editing rounding and overflow fixes.
- Project-selector sizing adjustments for smaller displays.

## Download And Use

Extract the entire Windows ZIP into a writable folder and start
`Start-ShadowWorld-Noggit.cmd` or `noggit.exe`. The package includes Release
runtime libraries, database definitions, themes and a listfile. It excludes
personal projects, logs, debug libraries, backups and development artifacts.
If needed, install the bundled Visual C++ x64 redistributable.

Modern projects save modern terrain and M2/WMO placement data. WotLK projects
keep WotLK-format saving. Up to 16 terrain texture layers are enabled across
all four project types; acceptance in-game depends on the target client.
Cross-version conversion is planned, not included.

Back up maps before editing. Multi-file rollback is not a guarantee against
power loss or process termination during a commit. This hotfix does not claim
that all reported Retail/Forever material and animation issues are resolved.
Unknown future DB2 layouts still need appropriate definitions. In-editor
save/reopen verification is not a test of every map in every game client.
