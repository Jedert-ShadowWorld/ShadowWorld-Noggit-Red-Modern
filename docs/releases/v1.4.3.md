# ShadowWorld Noggit v1.4.3

One Windows executable for WotLK, Shadowlands 9.2.7, Retail 12.1, and Forever 1.60.x projects.

## Changes

- Retail 12.1 WDC4/WDC5 tables now select an existing DBD definition by layout hash when a newer client build number is not yet listed. The supplied 12.1.0.69933 `Map.db2` has the supported `75863E23` layout.
- The project selector adapts to smaller display sizes instead of requiring a fixed 1600 x 900 window.
- Alphamap PNG import/export now covers layers 1-15, and importing respects the cleanup option.
- Fixed alpha rounding and 8-bit sum overflow in multi-layer texture editing.

## Notes

- A matching DB2 layout does not guarantee compatibility with every future client update. Unknown layouts still require a new definition.
- The Retail map-list failure was reproduced from a log and the supplied DB2 header; the updated executable was built successfully. In-editor confirmation on the affected setup is still needed.
- Multi-layer painting changes are compiled but still need visual and in-game checks on the reported map. Back up maps before editing.
- Custom `Map.db2` records are not replaced by this release. Keep your project's custom data and use files appropriate to the matching client/server.
- Modern projects save modern terrain and M2/WMO placement data; WotLK projects keep WotLK-format saving. The editor allows up to 16 terrain texture layers in all four project types, subject to client compatibility.
