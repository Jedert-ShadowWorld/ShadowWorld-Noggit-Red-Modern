# ShadowWorld Noggit v1.4.4 - MTXP and Retail Save Fix

## Changes

- MTXP/MHID height-texture metadata is loaded, rendered and retained when
  texture layers are edited, reordered or restored with undo/redo.
- Texture-only modern ADT saves preserve original OBJ0/OBJ1 data when model
  placements are unchanged. Existing placement flags and derived WMO bounds
  no longer cause unnecessary LOD rewrites.
- Rotation comparisons accept the editor's exact normalization result,
  including float rounding at 180 degrees. Actual transform changes remain
  subject to object-save validation.
- SoundKit compatibility views use bulk record creation instead of repeated
  insertion during project startup.
- Listfile refresh checks release metadata before downloading. Unchanged
  files are reused; failed downloads retain a usable existing local CSV.
- The CascLib local/high-resolution override is included in this repository
  rather than depending on an unpublished file inside a submodule.

## Verification

Windows x64 build completed on 2026-10-11. The project author confirmed the
previously failing Retail painting/save operation now succeeds in Noggit.
No project map files were manually patched to make the test pass.

Regression tests passed for eight OBJ1 layouts, real 3075_35_34 and 3075_37_34
fixtures, angle boundaries and detection of actual 0.01-degree rotation edits.
Malformed LOD rejection, multi-part save rollback, new-map creation, native
Map DB2 writing, eleven editor DB2 tables, texture metadata, GPU terrain
rendering, bulk DBC creation and listfile updates were also tested.

## Packages

The Windows x64 ZIP includes the tested executable, release runtime libraries,
database definitions, themes and a listfile. Extract the entire archive and
run `Start-ShadowWorld-Noggit.cmd`. Personal projects, configuration paths,
logs, debug binaries and old executable backups are excluded.

The complete-source ZIP includes repository files, initialized submodules
and pinned build dependency source snapshots, without Git credentials/history
or personal projects. The normal Git repository remains the canonical source.

Back up maps before editing. Unsupported actual object/LOD edits still report
an error; this release does not disable validation or claim to resolve every
modern rendering issue. In particular, the black geometry visible in the
user's save-test screenshots has not been verified fixed.
