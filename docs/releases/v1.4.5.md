# ShadowWorld Noggit v1.4.5 — Retail models, map saves and preview controls

Integrated PR #8 (41ecba58) into the canonical source, retaining local Retail 12.1.5 native DB2, ray-picking, custom listfile and third OBJ1 LOD-range fixes.

## Changes
- Modern M2/SKIN/SKEL animation loading and layered M2/WMO materials.
- Retail preview tab: model quality, geometry LOD, animation playback and decals. Preview settings do not reduce exported map detail.
- Metadata-preserving split ADT saves, scoped UID review/repair and cross-tile placement handling.
- Terrain/liquid LOD, diffuse/normal map textures, heightmaps and terrain occlusion updates, with pending-state tracking and retry behavior.
- PR review fixes: reject transfers losing OBJ1 coverage; mark repaired object LOD bounds pending; retain separate external M2 animation payloads for particles/ribbons after skeleton loading.
- Version 1.4.5 is displayed in the application title alongside the source revision.

## Validation and limits
All 30 standalone regression tests passed, including real OpenGL checks. The previously problematic 2720_40_31 OBJ0/OBJ1 pair passed read-only preservation/edit checks. Ray picking regression passed.
Full editor and game-client visual parity is not established by these tests. Unsupported layouts remain guarded; see docs/retail-models.md, docs/uid-repair.md and docs/derived-map-results.md.

## Packages
Extract the full Windows x64 ZIP and run Start-ShadowWorld-Noggit.cmd. No personal projects, machine-specific paths or debug runtimes are included. Preserve your existing project files and configuration when upgrading.
The complete-source ZIP includes initialized submodules and dependency source snapshots. For a Git checkout, initialize submodules and run tools/apply-local-dependencies.ps1 to apply the tracked local dependency compatibility patches. tools/build-recovered.cmd uses the maintainer's local build paths; adapt those paths for other machines.
